Track 04

Q-Learning to DQN

Q-learning works with tables in small state spaces. DQN approximates Q-values with neural networks for larger observations.

Lesson map

Intuition

Estimate “how good” each action is in each state, then choose high-value actions while still exploring.

Formalism

Q(s,a) ← Q(s,a) + α[r + γ max_a'Q(s',a') - Q(s,a)]

DQN keeps same target idea but replaces table lookup with Qθ(s,a) from a neural network.

Worked Example

If current Q is 0.50, reward is 1, max next Q is 0.70, α=0.1, γ=0.9, target is 1.63 and updated Q moves toward it.

Common Mistakes

  • Using too-high learning rates with bootstrapped targets.
  • No replay warmup before gradient updates.
  • Updating target network too frequently.
