If RL feels abstract, anchor on one idea: optimize long-run consequences, not one-step rewards.

Intuition

An RL agent behaves like a manager making sequential decisions under uncertainty. Good RL behavior may sacrifice immediate reward to reach better future states.

Formalism

At time t, the agent observes state s_t, takes action a_t, receives reward r_{t+1}, and transitions to s_{t+1}. Objective: maximize expected return.

Return: G_t = r_{t+1} + γr_{t+2} + γ²r_{t+3} + ...

Worked Example

Robot vacuum chooses between "quick clean" (+1 now) vs "charge then deep clean" (-0.2 now, +2 later). With high γ, second policy wins.

Common Mistakes

  • Optimizing immediate reward only.
  • Treating sparse reward as algorithm failure.
  • Using γ near 1 without stable learning setup.

Summary

Master the language of state, action, reward, policy, and return before touching complex algorithms. This reduces confusion later.
