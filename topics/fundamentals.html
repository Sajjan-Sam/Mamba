Reinforcement Learning in Very Easy Language

RL means learning by trial and feedback. The agent does an action, gets a reward, and improves decisions over time.

Core Building Blocks

  • Agent: learner/decision maker.
  • Environment: world where agent acts.
  • State (s): current situation.
  • Action (a): available choice.
  • Reward (r): immediate score.
  • Policy (π): rule mapping state to action.

Simple Example: Robot Vacuum

State: dirty room. Action: clean left or right. Reward: +1 for cleaned area, -0.2 for battery use. Goal: maximize total long-term reward, not just one step.

This teaches delayed reward: sometimes you do a small-cost action now to get bigger reward soon.

Return and Discount

The return is total future reward: G = r1 + γr2 + γ²r3 + .... If γ is close to 1, the agent cares about future strongly. If γ is low, agent is short-term focused.
