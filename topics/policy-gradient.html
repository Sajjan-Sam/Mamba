Policy Gradient in Plain English

Instead of learning values first, policy gradient learns a policy directly: how likely each action should be.

Core idea

Increase probability of actions that led to good returns; decrease probability of actions that led to bad returns.

θ ← θ + α ∇θ log πθ(a|s) · G

Variance Reduction

  • Use a baseline (like value estimate) to stabilize learning.
  • Advantage = return - baseline.
  • Actor-Critic combines policy and value learning.

Where this shines

Continuous control problems like robot joints, drone control, and nuanced motor actions where discrete Q tables are not enough.
