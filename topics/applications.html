Applications & Deployment

Use RL when decisions are sequential, feedback is delayed, and simulation/evaluation loops are feasible.

Intuition

RL is strongest when today's action changes tomorrow's opportunities. If problem is one-shot prediction, supervised learning is often better.

Formalism

Production objective should optimize long-horizon utility under constraints: safety, fairness, latency, and observability.

Deployment policy = maximize expected return subject to risk and governance constraints.

Common Mistakes

  • No simulator realism checks before rollout.
