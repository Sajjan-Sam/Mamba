Algorithm

From Q-Table to Deep Q Network

Q-Learning learns action values directly. DQN uses a neural network when states are too many for a table.

Q-Learning Update

Q(s,a) ← Q(s,a) + α[r + γ max_a' Q(s',a') - Q(s,a)]
  • α = learning rate
  • γ = discount factor
  • Bootstrap target from next state's best action

Why DQN worked well (easy view)

  • Replay buffer: random mini-batches reduce correlation.
  • Target network: stable training target.
  • Reward clipping: smoother optimization.

Good for high-dimensional spaces like images in Atari.

Mini Walkthrough Example

State: game frame features. Action: left/right/jump/fire. Reward: game score change. The model predicts Q-values for all actions and picks the max during exploitation. During training, it sometimes takes random action for exploration.
